# PDF Notes Studio · PDF 笔记室

一款完全本地化运行的 PDF 桌面工作台 —— 在 PDF 上做笔记、划重点、去水印、建大纲、插图表与思维导图，一键导出带批注的 PDF。

> 所有处理均在本地完成，不上传任何文件；笔记按文件指纹自动保存，重开即恢复。

---

## ✨ 功能特性

### 🖍 批注工具
- **荧光笔** — 35% 半透明高亮，不遮挡原文
- **画笔** — 平滑贝塞尔曲线手写，矢量存储
- **文字** — 点击页面任意位置输入，Enter 提交
- **橡皮** — 按笔画粒度擦除，支持局部擦拭
- 5 种批注色 × 每工具独立 3 档粗细
- 撤销 / 重做（跨页全局栈），按页清空

### 💧 去水印
- **文字水印自动检测** — 扫描全文文本层，找出在 ≥70% 页面重复出现的文字（水印典型指纹），勾选后按精确坐标自动遮盖
- **印章与批注移除** — 导出时剔除 Stamp / Watermark / FreeText 类印章，保留链接与表单控件
- **手动遮盖工具 (W)** — 拖矩形遮盖图片型水印 / Logo / 敏感信息，自动采样页面底色，与背景融为一体
- 三种方式可叠加使用，遮盖可单独回退而不丢批注

### 📑 大纲导航
- **自动检测** — 读取 PDF 书签树，层级缩进展示，点击跳页，随阅读位置实时高亮当前章节
- **自定义大纲** — 无书签的文档可手动添加条目（跟随当前页）、重命名、排序、删除，随文件持久化
- 与「页面」缩略图栏双页签切换

### 📊 图表与思维导图 (G)
- **三种数据图表** — 柱状 / 折线 / 饼图（甜甜圈），表单实时编辑 + 实时预览，最多 8 组数据
- **可交互思维导图** — 拖动布局、双击重命名、增删分支（连子树）、一键对称整理
- **节点级样式** — 每个节点可自定义文字、字号（4 档）、字重、文字色、节点底色、连线色
- **多主题** — 支持多个根主题并存，各自展开子树
- 放置到页面后可选中、拖动、角点缩放、双击重新编辑、Delete 删除

### 🎨 三套主题 + 跟随系统
| 主题 | 风格 |
|---|---|
| **暖纸书房**（默认） | 米白纸感底 · 赤陶强调 · 衬线展示字体 |
| **石墨工作站** | 石墨色阶 · 琥珀信号色 · 锐利边线 |
| **午夜蓝** | 藏青面板 · 电光青强调 |
| **跟随系统** | 浅色自动用暖纸 / 深色自动用石墨 |

首帧预载零闪烁，偏好持久化。

### 🌸 动效设计（温暖活泼风）
- 启动编排：标题栏落下 → 工具栏 → 侧栏 → 状态栏交错入场
- 画布动效：笔迹生长、图表 Q 弹落位、文字弹入、遮盖展开、选中框蚂蚁线 + 手柄呼吸
- 微交互：工具切换滑动指示器、按钮按压回弹、缩略图悬停抬起
- 庆祝时刻：导出成功 42 片主题色纸屑
- 全部走单一 rAF 引擎按需启停；`prefers-reduced-motion` 下双重降级

### 📄 导出
- pdf-lib 以 2 倍分辨率将每页笔记（含图表、遮盖）嵌入原 PDF
- 原生保存对话框，输出「文件名-已批注.pdf」
- 可选移除印章类批注

## 🚀 安装使用

### 普通用户
1. 运行 `dist\PDF-Notes-Studio-Setup-1.0.0.exe`
2. 按向导完成安装（自动创建桌面图标 + 开始菜单 + 卸载程序）
3. 双击桌面「PDF Notes Studio」即可使用，**完全离线**

也可以直接运行 `dist\win-unpacked\PDF Notes Studio.exe`（免安装绿色版）。

### 开发者

```bash
# 环境要求：Node.js ≥ 18

# 1. 安装依赖（推荐走国内镜像）
npm install --registry=https://registry.npmmirror.com

# 2. 开发运行
npm start

# 3. 打包 NSIS 安装包（输出到 dist/）
#    国内网络建议带上镜像环境变量：
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR='https://npmmirror.com/mirrors/electron-builder-binaries/'
$env:ELECTRON_BUILDER_CACHE='.\.eb-cache'
npm run dist
```

## 📁 项目结构

```
PDF Notes Studio/
├── main.js            # Electron 主进程（无边框窗口、原生保存对话框）
├── preload.js         # contextIsolation 安全桥接
├── index.html         # 渲染进程（UI + 批注引擎 + 全部业务逻辑，单文件）
├── icon-gen.js        # 品牌图标生成脚本（离屏 canvas → icon.ico/png）
├── vendor.js          # 一次性脚本：下载 CDN 资源到 vendor/ 实现离线
├── vendor/            # 本地化的 pdf.js / pdf-lib / 全部字体（woff2）
├── build/             # 应用图标（icon.ico / icon.png）
└── dist/              # 构建产物（安装包 + win-unpacked）
```

## 🛠 技术栈

- **Electron 31** — 桌面容器（无边框窗口 + IPC 原生对话框）
- **pdf.js 3.11** — PDF 渲染（DPR ≤ 2 高清、懒渲染）
- **pdf-lib** — 导出时嵌入批注层
- **原生 Canvas** — 双层画布（PDF 层 + 批注层）、图表与思维导图手绘渲染
- **CSS 设计令牌** — 三主题 `data-theme` 属性切换体系
- 零 UI 框架、零运行时网络依赖

## 💾 数据存储

笔记 / 自定义大纲 / 去水印设置按 **文件指纹**（名称 + 大小）存入 localStorage，与文件路径无关 —— 移动文件位置后重开仍能恢复。

---

## ⚠️ 注意事项

- 去水印功能请仅对你**有权处理**的文档使用
- 批注导出为图像层叠加，导出后的 PDF 文字层不受影响，但批注本身不可再编辑
- `vendor.js` 仅在首次搭建或升级依赖库时需要运行，日常开发直接 `npm start`
